# CA6002
# 选题概述 

选题名称 

不同特征复杂度下的农产品品种识别：SVM与随机森林在水稻和干豆数据集上的性能比较及可视化分析 

项目旨在研究：面对同类农产品视觉特征数据，算法的相对表现是否会因为类别数量、特征维度和类别重叠程度不同而发生变化。 

 

# 数据集 

1. Rice数据集 
包含 3,810粒水稻样本； 
识别Cammeo和Osmancik两个品种； 
包含面积、周长、主轴长度、短轴长度、偏心率等 7个图像形态特征； 
属于相对简单的二分类任务。 [archive.ics.uci.edu] 

2. Dry Bean数据集 
包含 13,611粒干豆样本； 
识别7种干豆品种； 
包含面积、周长、轴长、长宽比、圆度和紧密度等 16个图像形态特征； 
类别更多、特征关系和类别重叠情况更加复杂。 [archive.ics.uci.edu], [archive.ics.uci.edu] 
两个数据集都来自农产品颗粒图像，并通过图像分割提取形态特征，具有较高的可比性。 

 
# 比较算法 
RBF支持向量机（SVM） 
适合连续数值型特征； 
通过核函数学习平滑的非线性分类边界； 
预计在类别较少、特征维度较低的Rice数据集上表现较好； 

随机森林（Random Forest） --通过组合多棵决策树完成分类； 
能够捕获特征之间的非线性关系和交互； 
预计在类别较多、特征关系更复杂的Dry Bean数据集上具有优势； 
主要调节树数量、树深度及叶节点最小样本数等参数。

1. 原始数据分析

2. 模型训练与调优分析

交叉验证准确率分布；

3. 模型结果与错误分析

模型稳定性对比。
